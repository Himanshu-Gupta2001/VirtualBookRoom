Update Opt In Pending Statuses to "Opt In" when subscribers engage via - Preference Page

Description

As the lead for data management, I want leads/contacts that have an “Opt In Pending” Consent status to be updated to “Opt In” when they confirm preference updates via the Preference Page, so that we can align all Marketing Cloud processes to change Consent Status when the user performs any enrollment activities.

When Leads/Contacts are initially created in Sales Cloud, they have a default Consent status of “Opt In Pending”. Currently, when a user submits a web form, we are updating all Opt In Pending statuses to “Opt In”. The same rule should be applied in other areas where a user can perform enrollment activities so that we can maintain a consistent process across all functions.

Acceptance Criteria


GIVEN we do not update Consent Status for anyone who is already in one of the "opt in" statuses
WHEN a lead or contact clicks Saves Updates on the Preference Page
AND their Consent Status IS NOT "Opt In"
THEN update their Consent Status to "Opt In"
AND the Consent Capture Date should be the current date/time
BUT do not update their Consent Status if it is already "Opt In"
