Update Source to "Preference Page" for existing self-enrolled preferences if Source is null

Description

As the email marketing lead, I want all null or blank Source values to be captured as “Preference Page” when a subscriber saves updates on the Preference Page, so that we can ensure all Source values are populated to show where the subscriber submitted the changes. Currently the Source field is not updated for pre-existing self-enrolled preferences by design. This requirement should be updated.

Background: There may be null values as Source was implemented only a year ago and there are historical records with no recorded sources if they have not interacted with one of key preference solutions. There may be other factors contributing to the null Source values, such as data processing automations own by the data management team.

Acceptance Criteria


SCENARIO 1: Update Source to "Preference Page" for existing self-enrolled preferences
GIVEN the Preference Page currently does not update the Source field for existing self-enrolled preferences
WHEN a subscriber clicks the "Save Updates" button on the Preference Page
AND there were existing self-enrolled preferences that the user did not uncheck
THEN record the Source of those preference as "Preference Page" only if Source was null or blank
BUT do not change the Source if there was an existing value
